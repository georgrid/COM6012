This is an example of a Lab 6 exercise solution.

1. You need to start in the ScalableML directory, which has been downloaded from GitHub. Then do 
1a. "cd Data"
1b. "wget http://files.grouplens.org/datasets/movielens/ml-latest-small.zip"
1c. "unzip ml-latest-small.zip"
1d. "cd .."

2. Put the Lab6_Exercise.py file into Code folder

3. In the Lab6_Exercise.py file, change your username in the SparkSession builder part.

4. Put Lab6_Exercise.sh into HPC folder.

5. Then 'cd HPC' folder and run 'sbatch Lab6_Exercise.sh'

6. Output file will be in the Output folder.
