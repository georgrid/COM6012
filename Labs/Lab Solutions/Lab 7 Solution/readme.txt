This is an example of Lab 7 exercise solution.

1. You need to go into ScalableML directory, which has been downloaded from GitHub.

2. Put .py files into Code folder

3. In the .py files, change your username in the SparkSession builder part.

4. Put Lab7_Exercise.sh into HPC folder.

5. Then 'cd HPC' folder and run 'sbatch Lab7_exercise.sh'

6. Output file will be in the Output folder.
