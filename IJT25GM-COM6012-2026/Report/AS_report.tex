For the \texttt{.ac.uk} hosts, the institution domain is extracted by first splitting each hostname using the full stop delimiter.
For example, the Sheffield hostname, \texttt{www.shef.ac.uk}, is split into \texttt{["www", "shef", "ac", "uk"]}.
The final three labels are concatenated together, resulting in \texttt{shef.ac.uk}, which represents the institution domain.
Different hosts from the same institution (\texttt{cs.shef.ac.uk}, \texttt{www.shef.ac.uk}, etc.) are grouped together within the Sheffield domain.

Listing \ref{lst:institution_extraction} shows the Spark implementation of the method described above.
\begin{lstlisting}[language=Python,
                   caption={Institution domain extraction and aggregation.},
                   label={lst:institution_extraction}]
academic_hosts = logs.filter(col("host").endswith(".ac.uk"))

split_host = split(col("host"), "\\.")

academic_domains = academic_hosts.select(
    col("host"),
    concat_ws(".",
        element_at(split_host, -3),
        element_at(split_host, -2),
        element_at(split_host, -1)
    ).alias("institution")
)

institution_counts = academic_domains.groupBy("institution") \
    .count() \
    .withColumnRenamed("count", "total_requests")
\end{lstlisting}
